# mama-app.ru — публичный сайт MAMA

Статический сайт для домена **mama-app.ru**: описание приложения MAMA, контакты,
политика конфиденциальности и реквизиты **ООО ТД «ГАРАНТ»**. Нужен для повторного
согласования имени отправителя SMS.RU/T2 (оператор требует открытый сайт с видимыми
названием компании и ИНН). Сайт **статический** и не зависит от FastAPI backend и от
сервера mama-api-01.

## Публикация (3 шага владельца)
1. **Реквизиты заполнены** подтверждёнными данными ООО ТД «ГАРАНТ» (ИНН 5032231151,
   ОГРН 1105032008960) из карточки предприятия. Workflow `pages.yml` всё равно проверяет
   и **не опубликует** сайт, если метки `[[ЗАПОЛНИТЬ...]]` вернутся в `index.html`/`privacy.html`.
   Перед финальной публикацией независимо сверьте ИНН/ОГРН в ЕГРЮЛ (egrul.nalog.ru).
2. **Включить GitHub Pages.** Settings → Pages → Build and deployment → Source:
   **GitHub Actions**. (Репозиторий должен быть public для бесплатного Pages с своим доменом.)
   Custom domain: `mama-app.ru` (файл `CNAME` уже в репозитории).
3. **Прописать DNS** (см. `DEPLOY-AND-DNS.md`), включить «Enforce HTTPS».

После заполнения реквизитов push в `main` запускает проверку и публикацию автоматически.

## Файлы
- `index.html` — главная (блок «ООО ТД «ГАРАНТ» + ИНН» виден на странице).
- `privacy.html` — политика конфиденциальности.
- `styles.css`, `robots.txt`, `CNAME` (= `mama-app.ru`).
- `DEPLOY-AND-DNS.md` — точные DNS-записи и проверки.
- `.github/workflows/pages.yml` — публикация с защитой от пустых реквизитов.

Никаких секретов, ключей или backend-кода здесь нет.
